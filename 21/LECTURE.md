# AI конспект для лекции #21

## Группировка: локальные альтернации и вложенные скобки

Круглые скобки `()` в регулярных выражениях выполняют группировку, позволяя:

1. **Локальные альтернации** — альтернатива работает только внутри группы:

   ```javascript
   const regex = /(cat|dog) (barks|jumps)/;
   // Ищет: cat или dog, затем пробел, затем barks или jumps
   console.log(regex.test("cat barks")); // true
   console.log(regex.test("dog jumps")); // true
   ```

2. **Вложенные скобки** — группы можно вкладывать друг в друга:
   ```javascript
   const regex = /((cat|dog) (barks|jumps))/;
   // Внешняя группа: всё выражение
   // Внутренняя группа 1: cat|dog
   // Внутренняя группа 2: barks|jumps
   ```

## Группы с квантификаторами

Квантификаторы применяются ко всей группе:

```javascript
const regex = /(ab)+/;  // одна или более последовательностей "ab"
console.log(regex.test("ab"));   // true
console.log(regex.test("abab")); // true
console.log(regex.test("abb"));  // false

const regex2 = /(cat|dog){2}/;  // cat или dog ровно 2 раза
console.log(regex2.test("catdog")); // true
console.log(regex2.test("dogcat")); // true
```

## Запоминание результата группы

По умолчанию группы **запоминают** (захватывают) совпавший текст. Результаты доступны после выполнения:

```javascript
const regex = /(cat|dog) (barks|jumps)/;
const match = "cat barks".match(regex);
console.log(match[0]); // "cat barks" — полное совпадение
console.log(match[1]); // "cat" — первая группа
console.log(match[2]); // "barks" — вторая группа
```

## Нумерация вложенных групп

Группы нумеруются **слева направо** по открывающей скобке:

```javascript
const regex = /((cat|dog) (barks|jumps))/;
// Группа 1: (cat|dog) (barks|jumps) — внешняя
// Группа 2: (cat|dog) — первая внутренняя
// Группа 3: (barks|jumps) — вторая внутренняя
```

**Правило:** номер группы определяется порядком открывающей скобки `(`.

## Альтернация и нумерация групп

При использовании альтернации внутри группы номера присваиваются **всем группам во всех вариантах**, независимо от того, какая альтернатива сработала:

```javascript
const regex = /(cat|(dog)) (barks|(jumps))/;
// Группа 1: (cat|(dog)) — внешняя
// Группа 2: (dog) — внутри первой альтернативы
// Группа 3: (barks|(jumps)) — внешняя
// Группа 4: (jumps) — внутри второй альтернативы
```

**Важно:** даже если альтернатива не сработала, группа всё равно получает свой номер. Несработавшие группы дают `undefined`:

```javascript
const regex = /(cat|(dog)) (barks|(jumps))/;
const match = "cat barks".match(regex);
console.log(match[1]); // "cat" — группа 1 сработала
console.log(match[2]); // undefined — (dog) не сработала
console.log(match[3]); // "barks" — группа 3 сработала
console.log(match[4]); // undefined — (jumps) не сработала
```

**Пример с вложенными альтернациями:**

```javascript
const regex = /((cat)|(dog))/;
// Группа 1: ((cat)|(dog)) — внешняя
// Группа 2: (cat) — первая альтернатива
// Группа 3: (dog) — вторая альтернатива

const match1 = "cat".match(regex);
console.log(match1[1]); // "cat" — группа 1
console.log(match1[2]); // "cat" — группа 2 сработала
console.log(match1[3]); // undefined — группа 3 не сработала

const match2 = "dog".match(regex);
console.log(match2[1]); // "dog" — группа 1
console.log(match2[2]); // undefined — группа 2 не сработала
console.log(match2[3]); // "dog" — группа 3 сработала
```

## Квантификаторы и группы

При повторении группы запоминается **последнее** совпадение:

```javascript
const regex = /(ab)+/;
const match = "ababab".match(regex);
console.log(match[1]); // "ab" — последнее совпадение группы
// Полное совпадение (match[0]) — "ababab"
```

## Опциональная группа: undefined если не найдена

Если группа опциональна (с `?`), она может отсутствовать:

```javascript
const regex = /(cat)? (dog)/;
const match = "dog".match(regex);
console.log(match[0]); // "dog"
console.log(match[1]); // undefined — группа не найдена
console.log(match[2]); // "dog"
```

## Именованные группы

Именованные группы позволяют обращаться к группе по имени, а не по номеру:

```javascript
const regex = /(?<animal>cat|dog) (?<action>barks|jumps)/;
const match = "cat barks".match(regex);
console.log(match.groups.animal); // "cat"
console.log(match.groups.action); // "barks"
```

**Синтаксис:** `(?<имя>...)`

**Важно:** именованные группы также доступны **по индексу** (как обычные группы), что полезно для обратной совместимости:

```javascript
const regex = /(?<animal>cat|dog) (?<action>barks|jumps)/;
const match = "cat barks".match(regex);
console.log(match[1]); // "cat" — доступ по индексу
console.log(match[2]); // "barks" — доступ по индексу
console.log(match.groups.animal); // "cat" — доступ по имени
console.log(match.groups.action); // "barks" — доступ по имени
```

## Две группы с одинаковым именем в разных альтернациях

Имя группы может использоваться в разных альтернативах:

```javascript
const regex = /(?<animal>cat|dog) (?<action>barks|jumps|runs)/;
// Группа animal — cat или dog
// Группа action — barks или jumps или runs
```

## Замена с использованием групп: replace

Метод `replace` использует группы в строке замены через `$n`:

```javascript
const str = "John Doe";
const regex = /(\w+) (\w+)/;
console.log(str.replace(regex, "$2, $1")); // "Doe, John"
```

**Специальные последовательности в строке замены:**

| Символ    | Значение               |
|-----------|------------------------|
| `$$`      | Символ $               |
| `$&`      | Всё совпадение         |
| `$\``     | Текст до совпадения    |
| `$'`      | Текст после совпадения |
| `$n`      | Группа n (n = 1-9)     |
| `$<name>` | Именованная группа     |

```javascript
const str = "Hello World";
const regex = /(\w+) (\w+)/;
console.log(str.replace(regex, "$&"));   // "Hello World"
console.log(str.replace(regex, "$`"));   // "" (до совпадения)
console.log(str.replace(regex, "$'"));   // "" (после совпадения)
```

## Именованные группы в функции replace

Вторым аргументом `replace` может быть функция:

```javascript
const str = "John Doe";
const regex = /(?<first>\w+) (?<last>\w+)/;
const result = str.replace(regex, (match, first, last, offset, string, groups) => {
    return `${groups.last}, ${groups.first}`;
});
console.log(result); // "Doe, John"
```

**Аргументы функции:**
1. `match` — полное совпадение.
2. `...groups` — значения всех групп (по порядку).
3. `offset` — позиция совпадения.
4. `string` — исходная строка.
5. `groups` — объект с именованными группами.

## Обратные ссылки внутри регулярного выражения

Обратные ссылки позволяют ссылаться на группы внутри самого регулярного выражения:

| Синтаксис  | Описание                            |
|------------|-------------------------------------|
| `\1`       | Ссылка на группу 1                  |
| `\2`       | Ссылка на группу 2                  |
| `\k<name>` | Ссылка на именованную группу `name` |

**Пример: сбалансированные кавычки**

```javascript
const regex = /(['"])(.*?)\1/;
console.log(regex.test('"text"'));   // true
console.log(regex.test("'text'"));   // true
console.log(regex.test('"text\''));  // false (кавычки не совпадают)
```

**Именованная обратная ссылка:**

```javascript
const regex = /(?<quote>['"])(.*?)\k<quote>/;
console.log(regex.test('"text"'));   // true
console.log(regex.test("'text'"));   // true
```

## Незапоминающие группы: `(?:...)`

Если группа нужна только для группировки, но не для захвата, используется `(?:...)`:

```javascript
// Запоминающие группы
const regex1 = /(cat|dog) (barks|jumps)/;
console.log("cat barks".match(regex1)[1]); // "cat"

// Незапоминающие группы
const regex2 = /(?:cat|dog) (?:barks|jumps)/;
console.log("cat barks".match(regex2)[1]); // undefined

// Группировка без захвата для квантификаторов
const regex3 = /(?:ab)+/;  // ab повторяется, но не запоминается
```

## Комбинирование запоминающих и незапоминающих групп

Можно смешивать оба типа в одном выражении:

```javascript
const regex = /(?:cat|dog) (?<action>barks|jumps)/;
const match = "cat barks".match(regex);
console.log(match[1]); // "barks" — только группа с именем
console.log(match.groups.action); // "barks"
```

**Вложение запоминающих групп внутрь незапоминающих:**

```javascript
// Незапоминающая группа содержит запоминающую
const regex = /(?:cat|dog) (?:(?<action>barks)|(?<action2>jumps))/;
const match = "cat barks".match(regex);
console.log(match[1]); // "barks" — первая запоминающая группа
console.log(match[2]); // undefined — вторая не сработала
console.log(match.groups.action); // "barks"
console.log(match.groups.action2); // undefined
```

**Вложение незапоминающих групп внутрь запоминающих:**

```javascript
// Запоминающая группа содержит незапоминающую
const regex = /(?<full>(?:cat|dog) (?:barks|jumps))/;
const match = "cat barks".match(regex);
console.log(match[1]); // "cat barks" — запоминающая группа
console.log(match.groups.full); // "cat barks"
```

**Комбинирование: запоминающая внутри незапоминающей внутри запоминающей:**

```javascript
const regex = /(?<sentence>(?:cat|dog) (?<action>barks|jumps))/;
// Группа 1: (?:cat|dog) — незапоминающая
// Группа 2: (?<sentence>...) — запоминающая, именованная
// Группа 3: (?<action>...) — запоминающая, именованная

const match = "cat barks".match(regex);
console.log(match[1]); // "cat barks" — группа 2
console.log(match[2]); // "barks" — группа 3
console.log(match.groups.sentence); // "cat barks"
console.log(match.groups.action); // "barks"
```

## Квантификатор над квантификатором

В некоторых случаях квантификаторы могут применяться к группам, содержащим другие квантификаторы:

```javascript
const regex = /(a+)+/;    // опасно: может привести к катастрофическому возврату
const regex2 = /(?:a+)+/; // тоже опасно
```

**Проблема:** такие выражения могут привести к катастрофическому возврату.

## Проблема производительности: катастрофический возврат

**Катастрофический возврат (catastrophic backtracking)** — ситуация, когда регулярное выражение экспоненциально долго обрабатывает строку из-за вложенных квантификаторов.

**Пример проблемного выражения:**

```javascript
const regex = /^(a+)+$/;  // страшная конструкция
const str = "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa!";
console.log(regex.test(str)); // Может выполняться экспоненциально долго!
```

**Почему это происходит:**

1. `a+` может захватить разное количество символов `a`.
2. `(a+)+` может повторяться разное количество раз.
3. При неудаче (строка заканчивается на `!`) движок перебирает все комбинации захвата `a+` внутри `(a+)+`.
4. Количество комбинаций растёт экспоненциально с длиной строки.

```text
Для строки из 30 символов 'a' + '!' — миллионы проверок.
Для 50 символов — миллиарды.
Для 100 символов — практически бесконечность.
```

**Решения катастрофического возврата:**

1. **Переписать выражение** — самый надёжный способ:
   ```javascript
   const regex = /^a+$/; // просто a+
   ```

2. **Использовать ленивые квантификаторы** (иногда помогает, но не всегда):
   ```javascript
   const regex = /^(a+)+?$/; // ленивый — но не всегда решает
   ```

3. **Ограничить количество повторений**:
   ```javascript
   const regex = /^a{1,50}$/; // ограничение
   ```

4. **Использовать паттерн с обратной ссылкой для эмуляции атомарности**:
   ```javascript
   const regex = /^(a+)\1+$/;
   ```

## Жадность vs ленивость

| Тип     | Синтаксис                  | Поведение                                |
|---------|----------------------------|------------------------------------------|
| Жадный  | `*`, `+`, `?`, `{n,m}`     | Захватывает максимально возможную строку |
| Ленивый | `*?`, `+?`, `??`, `{n,m}?` | Захватывает минимально возможную строку  |

```javascript
const str = "<div><span>Text</span></div>";

// Жадный — захватывает максимально
const greedy = /<.*>/;
console.log(str.match(greedy)); // "<div><span>Text</span></div>"

// Ленивый — захватывает минимально
const lazy = /<.*?>/;
console.log(str.match(lazy)); // "<div>"
```

## Эмуляция атомарной группы в JavaScript

В некоторых движках регулярных выражений (PCRE, Perl, Java) есть **атомарные группы** `(?>...)`, которые отключают возврат (backtracking) внутри группы. Это повышает производительность и предотвращает катастрофический возврат.

```javascript
// Без атомарной группы — может быть катастрофический возврат
const regex1 = /^(a+)+$/;

// С атомарной группой — возврат отключён
const regex2 = /^(?>(a+)+)$/;
```

**В JavaScript атомарные группы НЕ поддерживаются**. Однако существует паттерн, эмулирующий атомарность с помощью **позитивного просмотра вперёд** и **обратной ссылки**:

```javascript
// Паттерн: (?=(шаблон))\1
// Вместо /^(?>(a+)+)$/
const regex = /^(?=(a+))\1+$/;
// (?=(a+)) — проверяем, что a+ может совпасть, и захватываем в группу
// \1+ — используем захваченное значение для повторения
// Это эмулирует атомарность: возврат внутри (a+) отключён
```

**Примеры:**

```javascript
// Поиск повторяющихся слов
const regex = /\b(?=(\w+))\1+\b/;
console.log(regex.test("hello hello")); // true
console.log(regex.test("hello world")); // false

// Проверка, что строка состоит из повторяющихся блоков
const regex2 = /^(?=(\w+))\1+$/;
console.log(regex2.test("abcabc"));    // true
console.log(regex2.test("abcabcabc")); // true
console.log(regex2.test("abcabcx"));   // false

// Без эмуляции атомарности — потенциально опасное выражение
const dangerous = /^(a+)+$/; // может вызвать катастрофический возврат

// С эмуляцией атомарности — безопасно
const safe = /^(?=(a+))\1+$/;
```

**Как это работает:**

1. `(?=(a+))` — позитивный просмотр вперёд: проверяет, что `a+` может совпасть, и захватывает максимальную последовательность `a` в группу 1.
2. `\1+` — использует захваченное значение для повторения.
3. Так как просмотр вперёд не потребляет символы, а `\1+` использует уже захваченное значение, возврат внутри `(a+)` отключён.

**Важно:** этот паттерн не полностью идентичен атомарной группе, но для многих случаев (особенно для повторяющихся блоков) он работает и предотвращает катастрофический возврат.

## Итоги лекции

- **Группировка** — скобки `()` позволяют создавать локальные альтернации, применять квантификаторы к группе и захватывать текст для последующего использования.

- **Нумерация групп** — группы нумеруются слева направо по открывающим скобкам. При альтернации номера присваиваются всем группам во всех вариантах; несработавшие группы дают `undefined`.

- **Именованные группы** — `(?<name>...)` — доступ через `match.groups.name`. Также доступны по индексу (как обычные группы) для обратной совместимости.

- **Опциональные группы** — группы с `?` могут отсутствовать, возвращая `undefined`.

- **Обратные ссылки** — `\1` (по номеру) и `\k<name>` (по имени) позволяют ссылаться на ранее захваченный текст внутри регулярного выражения. Используются для поиска повторяющихся конструкций (сбалансированные кавычки, повторяющиеся слова).

- **Замена с группами** — в `replace`: `$1`, `$2`, `$<name>` в строке замены или функция-колбэк, получающая группы как аргументы.

- **Незапоминающие группы** — `(?:...)` — группировка без захвата. Используются для применения квантификаторов или альтернаций, когда захват не нужен. Могут быть вложены в запоминающие группы и наоборот.

- **Жадность vs ленивость** — `*`, `+`, `?`, `{n,m}` (жадные) захватывают максимально возможную строку; `*?`, `+?`, `??`, `{n,m}?` (ленивые) — минимально возможную.

- **Катастрофический возврат** — проблема производительности из-за вложенных квантификаторов (например, `(a+)+`). При неудаче движок перебирает экспоненциальное число вариантов, что может привести к зависанию.

- **Атомарные группы** — `(?>...)` отключают возврат внутри группы, предотвращая катастрофический возврат. В JavaScript отсутствуют, но эмулируются паттерном `(?=(шаблон))\1` (позитивный просмотр вперёд + обратная ссылка).
