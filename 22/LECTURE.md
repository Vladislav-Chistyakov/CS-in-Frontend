# AI конспект для лекции #22

## Движение по строке

Движок регулярных выражений обрабатывает строку последовательно, слева направо, пробуя различные варианты совпадений. Когда он находит частичное совпадение, он "запоминает" позицию в строке и в случае неудачи может вернуться к предыдущей позиции и попробовать другой путь. Этот механизм называется **возвратом (backtracking)**.

```javascript
const regex = /a+b/;
// Движение:
// a — совпало, двигаемся дальше
// a — совпало, двигаемся дальше
// ... — пока есть a
// b — совпало, успех
// Если b не найдена — возврат (backtracking)
```

## Опережающие проверки (lookahead)

**Опережающая проверка** позволяет проверить, что за текущей позицией следует определённый шаблон, **без перемещения** по строке. Это означает, что символы, проверенные в lookahead, не включаются в совпадение.

| Тип                  | Синтаксис | Значение                                |
|----------------------|-----------|-----------------------------------------|
| Позитивный lookahead | `(?=...)` | Проверяет, что шаблон следует дальше    |
| Негативный lookahead | `(?!...)` | Проверяет, что шаблон НЕ следует дальше |

```javascript
// Позитивный lookahead: найти "cat" только перед "dog"
const regex = /cat(?= dog)/;
console.log(regex.test("cat dog"));  // true
console.log(regex.test("cat fish")); // false

// Негативный lookahead: найти "cat" не перед "dog"
const regex2 = /cat(?! dog)/;
console.log(regex2.test("cat fish")); // true
console.log(regex2.test("cat dog"));  // false
```

## Запоминание группы с опережающей проверкой

Внутри lookahead можно использовать захватывающие группы:

```javascript
const regex = /(?=(\d+))abc/;
// \d+ внутри lookahead — проверяет, что за позицией следуют цифры
// и захватывает их в группу 1
const match = "123abc".match(regex);
console.log(match[1]); // "123" — группа захвачена из lookahead
```

## Атомарные группы

В некоторых движках есть атомарные группы `(?>...)`, отключающие возврат. В JavaScript их нет, но существует паттерн эмуляции:

```javascript
// Вместо атомарной группы используем lookahead + обратную ссылку
// Атомарный паттерн: (?=(шаблон))\1
const regex = /^(?=(a+))\1+$/;
// Проверяем a+, захватываем, повторяем без возврата
```

## Опережающие проверки с квантификаторами

Квантификаторы могут применяться к опережающим проверкам, что позволяет создавать мощные паттерны для проверки строк на наличие или отсутствие подстрок в любом месте строки.

**Пример: проверка, что строка не содержит "/node_modules/"**

```javascript
const isLocalPath = /^((?!\/node_modules\/).)*$/;
console.log(isLocalPath.test("/foo/bar/bla")); // true
console.log(isLocalPath.test("/node_modules/foo/bar/bla")); // false
console.log(isLocalPath.test("/foo/node_modules/bar/bla")); // false
```

**Как это работает:**

1. `^` — начало строки.
2. `(?!\/node_modules\/)` — негативная опережающая проверка: проверяет, что с текущей позиции НЕ начинается `/node_modules/`.
3. `.` — любой символ.
4. `*` — квантификатор, применяющийся ко всей группе `((?!\/node_modules\/).)`.
5. `$` — конец строки.

Таким образом, выражение читается как: "строка должна состоять из любых символов, но ни один из них не должен быть началом последовательности `/node_modules/`".

**Другие примеры использования:**

```javascript
// Проверка, что строка содержит хотя бы одну цифру
const hasDigit = /^(?=.*\d).*$/;
console.log(hasDigit.test("abc123")); // true
console.log(hasDigit.test("abc"));    // false

// Проверка, что строка содержит хотя бы одну заглавную и одну строчную букву
const hasUpperAndLower = /^(?=.*[a-z])(?=.*[A-Z]).*$/;
console.log(hasUpperAndLower.test("Hello")); // true
console.log(hasUpperAndLower.test("hello")); // false
console.log(hasUpperAndLower.test("HELLO")); // false

// Проверка, что строка НЕ содержит пробелов
const noSpaces = /^(?!.*\s).*$/;
console.log(noSpaces.test("hello world")); // false
console.log(noSpaces.test("hello"));       // true

// Проверка, что строка заканчивается на ".js" ИЛИ ".ts"
const isJSTsFile = /^(?!.*\.(js|ts)$).*$/;
console.log(isJSTsFile.test("file.js"));  // false
console.log(isJSTsFile.test("file.ts"));  // false
console.log(isJSTsFile.test("file.py"));  // true
```

**Важно:** квантификатор `*` над группой с lookahead позволяет проверить условие для КАЖДОЙ позиции в строке. Это мощный приём для проверки глобальных условий (например, "строка не содержит X" или "строка содержит X и Y").

## Ретроспективные проверки (lookbehind)

**Ретроспективная проверка** проверяет, что ПЕРЕД текущей позицией находится определённый шаблон.

| Тип                   | Синтаксис  | Значение                            |
|-----------------------|------------|-------------------------------------|
| Позитивный lookbehind | `(?<=...)` | Проверяет, что шаблон был раньше    |
| Негативный lookbehind | `(?<!...)` | Проверяет, что шаблон НЕ был раньше |

```javascript
// Позитивный lookbehind: найти "cat" только после "dog"
const regex = /(?<=dog )cat/;
console.log(regex.test("dog cat"));  // true
console.log(regex.test("bird cat")); // false

// Негативный lookbehind: найти "cat" не после "dog"
const regex2 = /(?<!dog )cat/;
console.log(regex2.test("bird cat")); // true
console.log(regex2.test("dog cat"));  // false
```

**Важно:** lookbehind в JavaScript поддерживается только в современных браузерах (ES2018+).

## Совмещение lookbehind и lookahead

Можно комбинировать обе проверки для точного поиска в контексте:

```javascript
// Найти "cat", перед которым "dog" и после которого "fish"
const regex = /(?<=dog )cat(?= fish)/;
console.log(regex.test("dog cat fish")); // true
console.log(regex.test("dog cat bird")); // false
console.log(regex.test("bird cat fish")); // false
```

## Свойство lastIndex у регулярного выражения

Свойство `lastIndex` хранит позицию, с которой будет начат следующий поиск. Используется с флагами `g` и `y`.

```javascript
const regex = /cat/g;
console.log(regex.lastIndex); // 0
regex.test("cat cat cat");
console.log(regex.lastIndex); // 3
regex.test("cat cat cat");
console.log(regex.lastIndex); // 7
```

**Важно:** `lastIndex` сбрасывается при неудачном поиске.

## Флаги компиляции регулярных выражений

| Флаг | Название    | Описание                                          |
|------|-------------|---------------------------------------------------|
| `g`  | global      | Глобальный поиск всех совпадений                  |
| `i`  | ignoreCase  | Игнорирование регистра                            |
| `m`  | multiline   | Многострочный режим (`^` и `$` для каждой строки) |
| `u`  | unicode     | Поддержка Unicode (суррогатные пары, `\p{...}`)   |
| `y`  | sticky      | Поиск только с позиции `lastIndex`                |
| `s`  | dotAll      | Символ `.` совпадает с `\n`                       |
| `v`  | unicodeSets | Расширенный Unicode (ES2024)                      |

## Флаг g (global)

`g` позволяет найти все совпадения в строке, а не только первое.

```javascript
const str = "cat dog cat";
const regex = /cat/g;
console.log(str.match(regex)); // ["cat", "cat"]
console.log(str.replace(regex, "bird")); // "bird dog bird"
```

## Нюансы test с флагом g

`test()` с флагом `g` изменяет `lastIndex` при каждом вызове:

```javascript
const regex = /cat/g;
console.log(regex.test("cat")); // true
console.log(regex.lastIndex); // 3
console.log(regex.test("cat")); // false (поиск с позиции 3)
console.log(regex.lastIndex); // 0 (сброс)
```

## Нюансы match с флагом g

`match()` с `g` возвращает массив всех совпадений, **без групп**:

```javascript
const regex = /(ca)t/g;
const str = "cat cat";
console.log(str.match(regex)); // ["cat", "cat"] — группы потеряны!
```

Для получения групп используйте `matchAll()`.

## Нюансы replace с флагом g

`replace()` с `g` заменяет все совпадения:

```javascript
console.log("cat cat".replace(/cat/g, "dog")); // "dog dog"
console.log("cat cat".replace(/cat/, "dog"));  // "dog cat"
```

## Нюансы matchAll с флагом g

`matchAll()` возвращает итератор по всем совпадениям с группами:

```javascript
const regex = /(ca)t/g;
const matches = "cat cat".matchAll(regex);
for (const match of matches) {
    console.log(match[0]); // "cat"
    console.log(match[1]); // "ca"
}
```

## Флаг i (ignore case)

Игнорирует регистр символов:

```javascript
console.log(/cat/i.test("CAT")); // true
console.log(/cat/i.test("Cat")); // true
```

## Флаг m (multiline)

В многострочном режиме `^` и `$` совпадают с началом и концом КАЖДОЙ строки:

```javascript
const str = "cat\ndog";
console.log(/^dog/.test(str));    // false (ищем в начале всей строки)
console.log(/^dog/m.test(str));   // true (ищем в начале строки)
```

## Флаг u (unicode)

Включает поддержку Unicode: суррогатные пары считаются одним символом, работают свойства `\p{...}`.

```javascript
console.log(/^.$/.test("😀"));   // false (суррогатная пара — 2 символа)
console.log(/^.$/u.test("😀"));  // true (один символ)
```

### Символьный класс \p{...}

Доступен только с флагом `u`:

```javascript
console.log(/\p{Script=Cyrillic}/u.test("А")); // true
console.log(/\p{Emoji}/u.test("😀"));          // true
console.log(/\p{Digit}/u.test("5"));           // true
```

**Популярные свойства:**

- `\p{Script=Cyrillic}` — кириллица.
- `\p{Emoji}` — эмодзи.
- `\p{Digit}` — цифры.
- `\p{Letter}` — буквы.
- `\p{Punctuation}` — пунктуация.

## Флаг y (sticky)

Поиск **только** с позиции `lastIndex`. Если на этой позиции нет совпадения — поиск завершается.

```javascript
const regex = /cat/y;
regex.lastIndex = 3;
console.log(regex.test("cat cat")); // true (начинаем с пробела, cat нет)
console.log(regex.lastIndex); // 0 (сброс при неудаче)

regex.lastIndex = 4;
console.log(regex.test("cat cat")); // true (начинаем с cat)
```

## Совмещение g и y

`g` и `y` можно комбинировать:

```javascript
const regex = /cat/gy;
regex.lastIndex = 4;
console.log(regex.test("cat cat")); // true
console.log(regex.test("cat cat")); // false (поиск с 7, cat нет)
```

## Флаг s (dotAll)

Символ `.` совпадает с переводом строки:

```javascript
const str = "cat\ndog";
console.log(/cat.dog/.test(str));  // false (точка не совпадает с \n)
console.log(/cat.dog/s.test(str)); // true
```

## Флаг v (unicodeSets)

Новый флаг `v` (ES2024) расширяет возможности `u`:

- Поддержка разности множеств: `[A-Z--C]` (A-Z без C).
- Поддержка пересечения: `[A-Z&&[^C]]`.
- Вложенные символьные классы.

```javascript
// ES2024
console.log(/[A-Z--C]/v.test("A")); // true
console.log(/[A-Z--C]/v.test("C")); // false
```

## Свойство source у RegExp

Возвращает исходный текст регулярного выражения:

```javascript
const regex = /cat/g;
console.log(regex.source); // "cat"
console.log(regex.flags);  // "g"
```

## Устаревшие статические свойства RegExp

В старых версиях JavaScript существовали глобальные свойства типа `RegExp.$1` и т.д. Они устарели и не рекомендуются к использованию.

## Методы строк могут принимать строку вместо RegExp

Методы строк `search`, `match`, `replace`, `split` принимают как регулярное выражение, так и обычную строку. Однако интерпретация строки зависит от метода.

```javascript
const str = "a.b.c";
```

**`split` и `replace` — строка как литерал:**

Эти методы интерпретируют переданную строку как **литеральный текст**, а не как регулярное выражение. Спецсимволы не имеют особого значения.

```javascript
// split — строка "." ищется буквально
console.log(str.split(".")); // ["a", "b", "c"]

// replace — строка "." ищется буквально
console.log(str.replace(".", "-")); // "a-b.c" (заменяет только первую точку)
```

**`search` и `match` — строка преобразуется в RegExp!**

Важное отличие: `search` и `match` **преобразуют строку в регулярное выражение**. Это значит, что спецсимволы (`.` `*` `+` `?` и др.) начинают работать как в регулярном выражении, что может привести к неожиданным результатам.

```javascript
// search — строка "." преобразуется в RegExp /./ (любой символ!)
console.log(str.search(".")); // 0 (первый символ 'a')
console.log(str.search(/\./)); // 1 (буквально точка)

// match — строка "." преобразуется в RegExp /./ (любой символ!)
console.log(str.match(".")); // ["a"] (первый символ)
console.log(str.match(/\./)); // ["."] (буквально точка)
```

**Пример с несколькими символами:**

```javascript
const text = "hello.world";

// search со строкой — точка как любой символ
console.log(text.search(".")); // 0 (первый символ 'h')
console.log(text.search(/\./)); // 5 (буквально точка)

// match со строкой — точка как любой символ
console.log(text.match(".")); // ["h"]
console.log(text.match(/\./)); // ["."]
```

**Важно:** если вы передаёте строку в `search` или `match` и хотите найти литеральный спецсимвол (`.` `*` `+` `?` и др.), вы должны **экранировать** его, как в регулярном выражении:

```javascript
// ❌ Неправильно: ищем любой символ
console.log("a.b".search(".")); // 0 (первый символ)

// ✅ Правильно: экранируем для литерального поиска
console.log("a.b".search("\\.")); // 1
console.log("a.b".match("\\.")); // ["."]

// ✅ Или просто используем RegExp
console.log("a.b".search(/\./)); // 1
```

**Разница в поведении:**

| Метод     | Строка `"."`         | RegExp `/\./`        |
|-----------|----------------------|----------------------|
| `split`   | Ищет точку буквально | Ищет точку буквально |
| `replace` | Ищет точку буквально | Ищет точку буквально |
| `search`  | **Любой символ!**    | Ищет точку буквально |
| `match`   | **Любой символ!**    | Ищет точку буквально |

**Рекомендация:**
- Для `replace` и `split` можно безопасно передавать строку.
- Для `search` и `match` всегда используйте RegExp, если хотите предсказуемого поведения.
- Если передаёте строку в `search` или `match` — экранируйте спецсимволы (`\\`).

## Итоги лекции

- **Движение по строке** — последовательный обход с возвратом (backtracking). Движок пробует различные варианты и возвращается к предыдущим позициям при неудаче.

- **Опережающие проверки (lookahead)** — `(?=...)` (позитивная, должно быть дальше) и `(?!...)` (негативная, не должно быть дальше). Не перемещают позицию в строке. Могут комбинироваться с квантификаторами для проверки условий на всём протяжении строки.

- **Ретроспективные проверки (lookbehind)** — `(?<=...)` (позитивная, должно быть раньше) и `(?<!...)` (негативная, не должно быть раньше). Поддерживаются в современных браузерах (ES2018+).

- **Захват в lookahead** — группы внутри `(?=...)` и `(?!...)` запоминаются и доступны по индексу или имени, несмотря на то, что lookahead не потребляет символы.

- **Атомарные группы** — в JavaScript отсутствуют. Эмулируются через паттерн `(?=(шаблон))\1` (позитивный lookahead + обратная ссылка), что предотвращает катастрофический возврат.

- **`lastIndex`** — свойство регулярного выражения, хранящее позицию для следующего поиска. Используется с флагами `g` и `y`. Сбрасывается при неудачном поиске.

- **Флаги**:
  - `g` — global: поиск всех совпадений. Влияет на поведение `test()`, `match()`, `replace()`.
  - `i` — ignoreCase: игнорирование регистра.
  - `m` — multiline: `^` и `$` работают для каждой строки, а не только для всей строки.
  - `u` — unicode: поддержка суррогатных пар, работа `\p{...}`.
  - `y` — sticky: поиск только с позиции `lastIndex`. При неудаче `lastIndex` сбрасывается в `0`.
  - `s` — dotAll: `.` совпадает с переводом строки `\n`.
  - `v` — unicodeSets: расширенная поддержка Unicode (ES2024), разность и пересечение множеств.

- **`matchAll()`** — возвращает итератор по всем совпадениям с группами (в отличие от `match()` с `g`, который возвращает только совпадения без групп).

- **Методы строк и строки вместо RegExp**:
  - `split` и `replace` — строка интерпретируется как **литеральный текст**.
  - `search` и `match` — строка **преобразуется в RegExp**, поэтому спецсимволы (`*`, `+`, `.`, `?` и др.) приобретают особое значение. Для литерального поиска спецсимволов в этих методах их нужно экранировать (`\\.`).
